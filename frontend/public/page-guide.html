⚡ Routing Architecture

App.js → routing/routing.jsx → UserLayout.jsx (Header + Footer wrapper) → Page Component
App.js → routing/routing.jsx → /auth (standalone — no layout)

All routes under <UserLayout> automatically get the Header and Footer. The /auth route is standalone.

Degree Navigation Flow

📚 3-Step Catalog Navigation (Home → Products)

Home / → Category Section → /main-degrees/:bookId → /sub-degrees/:bookId/:mainDegreeId → /categorized-products/:bookId/:mainDegreeId/:subDegreeId → /productpage/:id

The bookId parameter represents the study material type (e.g., solved papers, assignments).
mainDegreeId = degree type (e.g., BA, BCom, BCA). subDegreeId = programme (e.g., BA History).
